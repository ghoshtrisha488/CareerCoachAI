# 🎯 AI Interview Coach Application

An interactive, AI-powered interview practice platform designed to help candidates prepare for technical and non-technical job interviews through real-time feedback, personalized question sets, and realistic interview simulations.

---

## ✨ Features

- **Personalized Onboarding**: Customized interview tracks based on the candidate's target role, experience level, and industry.
- **AI-Powered Interview Simulations**: Practice with dynamic, context-aware interview questions tailored to specific job profiles.
- **Real-Time Feedback & Scoring**: Receive immediate actionable insights, answer quality scoring, and suggested response improvements.
- **Interactive Speech & Text Interface**: Practice answering either via text or voice inputs for realistic interview conditions.
- **Progress Tracking & Analytics**: Review past interview sessions, track score improvements, and identify areas for growth over time.
- **Smooth Animations & Modern UI**: Sleek, responsive interface built with fluid motion transitions for a stress-free preparation environment.

---

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS, Framer Motion
- **Build Tool**: Vite
- **Backend / Database**: Supabase / Node.js
- **AI Integration**: OpenAI API / Gemini API
